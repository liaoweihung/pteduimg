# 中藥外用貼布與處方外用藥：配方組合分析

本資料包分析現代產品的官方處方原文，並保留每個材料的原始名稱與原始處方。它不重新抓取官方資料，也不配對口服傳統母方。

- 範圍固定為 577 張：564 張藥膠布劑、13 張須由中醫師處方使用的非貼布外用產品。
- 13 張處方外用藥保留處方藥身分，不能視為 OTC 或成藥。
- 核心／添加／少用成分僅依群內產品的傳統藥材統計；不是療效證據、傳統母方或臨床推薦。
- 基質、色素、西藥／防腐成分與無法判定項目會另行分類，絕不混入藥材核心。
