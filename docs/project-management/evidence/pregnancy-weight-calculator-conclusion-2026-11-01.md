# 孕期體重增加計算器 快速結論（2026-11-01）

- 來源：國健署《孕媽咪衛教手冊》孕媽咪體重增加建議表（同 CR-2026-057），sourceCheckedAt 2026-11-01。建議文字只取手冊「懷孕期間不適於減重」與「建議找合格營養師做進一步的營養評估與諮詢」。

## 規則

依序：(1) 已增加 < 0 → 黃「體重低於孕前」；(2) 已增加 > 建議上限 → 紅「已超過建議上限」；(3) 雙胞胎且 BMI<18.5 → 中性「手冊無建議值」；(4) 雙胞胎或未滿 13 週 → 中性「尚未超過建議上限」；(5) P = 已增加 + 每週增加重量 × max(0, 280 − 孕期天數) ÷ 7（四捨五入至 0.1），P > 上限 → 黃、P < 下限 → 黃、其餘 → 綠。P 等於上下限屬範圍內。
