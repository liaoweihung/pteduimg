# 中成藥母方查詢交接說明

## 狀態

「中成藥母方查詢」已從公開網站的健康工具入口、藥品資料庫導覽與 PWA 離線快取移除。現有頁面與實作仍保留在 repository，供後續研究、驗證與重做使用；目前不應重新加入公開入口或離線快取。

## 資料規模

- 產品索引：21,196 筆產品。
- 母方表：204 個母方。
- 產品詳情：32 個分檔，檔名為 `products-00.json` 至 `products-31.json`。
- 產品索引與分檔位於 `data/tcm_formula_explorer/`。

## 保留原則

- 保留 `tcm_formula_explorer.html`、`css/tcm-formula-explorer.css` 與 `js/tcm-formula-explorer.js`。
- 保留 `data/tcm_formula_explorer/` 內的產品索引、母方表、32 個產品詳情分檔、分類與關聯分析檔。
- 保留 `scripts/prepare_tcm_formula_explorer.py` 與 `scripts/build_tcm_formula_relationships.py`，讓資料整理與分析結果可重現。
- 官方適應症與處方原文維持原樣，不因顯示或分析需求改寫。
- 不把 32 個產品詳情分檔合併成單一大型 JSON。
- 在重新完成產品定位、資料驗證與風險檢視前，不恢復公開網站入口或 PWA 離線快取。

## 目前問題

- 母方關係、加減藥材與相似度屬演算法推測，不是歷史源流定論或製造商聲明，容易被使用者誤認為官方判定。
- 舊交付資料曾有 Big5 顯示問題；目前整理程序只修復索引與母方表，產品詳情中的官方原文則刻意不改寫。
- 21,196 筆產品與 32 個詳情分檔雖採延遲載入，但索引、母方與多份分析檔仍會增加首次載入、離線更新及版本一致性的維護成本。
- 現有介面同時呈現官方資料與推測分析，資訊層級與證據來源的區隔仍不夠清楚。
- 關聯分析結果需要可追溯的產生版本、資料日期與驗證方法，才能安全對外解讀。

## 日後重做方向

1. 先定義目標使用者與用途，區分「官方藥證查詢」和「研究性母方相似度分析」。
2. 將官方欄位、推測結果、信心程度與計算方法分層呈現，為每筆推測提供清楚且持續可見的警語。
3. 建立可重現的資料管線、版本資訊、編碼檢查、筆數基準與抽樣驗證報告。
4. 評估改用伺服器端搜尋、較小索引或按需 API，避免把完整研究資料與分析資產納入靜態網站的核心下載範圍。
5. 重新設計搜尋與詳情流程，優先顯示官方原文，再由使用者主動展開研究性推測。
6. 在重新上線前，完成藥事專業審查、風險文案檢視、效能測試、無障礙檢查與行動裝置驗證。
