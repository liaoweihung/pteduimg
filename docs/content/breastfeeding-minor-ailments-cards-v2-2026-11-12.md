# 哺乳期間小毛病，可以用什麼藥？（圖卡文字 v2）

初稿 v2｜2026/11/12｜已依藥師審閱意見修訂，待確認後轉 JSON 內容包

---

## 系列共通說明

以下建議主要適用於哺餵足月、健康寶寶的媽媽。若寶寶早產、剛出生、有黃疸或其他疾病，使用藥物前請先詢問醫師或藥師。

- 哺乳期間生病，多數情況不需要停餵母乳。
- 若需服藥，可在**餵奶後立即服用**，減少寶寶接觸的藥量。
- 購買成藥前請先看成分，台灣許多綜合感冒藥含多種成分。

---

## 圖卡 1｜哺乳期間頭痛、發燒可以吃什麼？

**常見可選擇**

- **Acetaminophen（乙醯胺酚）**：退燒、止痛，哺乳期間常用選擇。
- **Ibuprofen（布洛芬）**：止痛、退燒、消炎，也是哺乳期間常用選擇。

**注意事項**

- 不建議自行使用 Aspirin（阿斯匹靈）來止痛退燒。
- 感冒複方藥可能重複含有退燒止痛成分，應確認成分，避免重複服用。
- 有胃潰瘍、氣喘或腎功能問題者，使用 Ibuprofen 前請先詢問醫師或藥師。

**⚠ 立即就醫**

產後出現劇烈頭痛、視力模糊、上腹痛或血壓升高，應立即就醫，排除產後子癲前症。

**底部提醒**

哺乳期間頭痛、發燒，不代表一定要停餵母乳。

---

## 圖卡 2｜哺乳期間鼻塞、流鼻水可以用什麼？

**優先選擇**

- **生理食鹽水噴鼻、洗鼻**：緩解鼻塞，適合先使用。
- **Loratadine、Cetirizine、Fexofenadine**：較不易嗜睡的抗組織胺，適合過敏性鼻炎。
- **Fluticasone、Budesonide 鼻噴劑**：過敏性鼻炎可考慮的局部用藥。
- **Oxymetazoline 鼻噴劑**：鼻塞嚴重時可短期使用，**最多 3 天**。

**需要注意**

- **Pseudoephedrine（偽麻黃鹼）、Methylephedrine（甲基麻黃鹼）**：可能減少母乳分泌，奶量尚未穩定時應避免自行使用。
- **Chlorpheniramine（氯苯那敏）** 等容易嗜睡的抗組織胺：可能讓寶寶嗜睡、喝奶變差，高劑量也可能影響奶量。
- 以上成分常出現在綜合感冒藥中，購買前請先確認成分。

**底部提醒**

哺乳期間選鼻塞藥，不只要注意寶寶，也要注意奶量。

---

## 圖卡 3｜哺乳期間咳嗽可以吃什麼？

**乾咳**

- **Dextromethorphan（右美沙芬）**：一般劑量進入母乳的量很低，可作為乾咳的用藥選擇。

**有痰咳嗽**

- 先補充水分、避免菸害與刺激物。
- **Acetylcysteine（乙醯半胱胺酸）**：化痰藥，可視症狀考慮。
- **Guaifenesin（癒創甘油醚）、Ambroxol（安布索）**：哺乳期資料有限，需要時請藥師評估，尤其寶寶為新生兒或早產兒時。

**應避免自行使用**

- 含 **Codeine（可待因）** 或 **Dihydrocodeine（二氫可待因）** 的止咳藥：可能造成寶寶嗜睡、呼吸變慢。
- 含 **Methylephedrine（甲基麻黃鹼）** 的複方止咳藥：可能減少奶量。
- 高酒精含量的止咳糖漿。
- 成分不清楚的複方感冒藥。

**⚠ 就醫警訊**

持續高燒、喘、胸痛、咳血或咳嗽持續惡化，應就醫。

**底部提醒**

買咳嗽藥水前先看成分，避開可待因類成分。

## 圖卡 4｜哺乳期間便祕可以用什麼？

**先從生活習慣改善**

增加飲水、膳食纖維，並依身體狀況適度活動。

**常見可選擇**

- **Magnesium oxide（氧化鎂）**：常用軟便藥；腎功能不佳者需先詢問醫師。
- **Psyllium（洋車前子殼）**：增加糞便體積，使用時要配足量水分。
- **Lactulose（乳果糖）**：滲透性軟便藥。
- **Macrogol／PEG（聚乙二醇）**：幫助糞便保留水分。
- **Sennoside（番瀉苷）、Bisacodyl、Glycerin 甘油栓劑**：必要時可短期使用。

**注意事項**

- 不需要因為一般便祕藥而自行停止哺乳。
- 腹痛明顯、嘔吐、血便或長期排便困難，應就醫確認原因。

**底部提醒**

多種常見便祕藥哺乳期間都可以使用，選擇適合的類型更重要。

---

## 圖卡 5｜哺乳期間拉肚子，可以吃止瀉藥嗎？

**第一步：補水**

- 優先使用 ORS（口服電解質補充液），少量多次補充。
- 一般腹瀉期間通常仍可繼續哺乳，並注意洗手衛生。

**必要時可考慮**

- **Loperamide（洛哌丁胺）**：進入乳汁的量很少，成人急性水瀉可短期使用。

**不建議自行使用**

- **Bismuth subsalicylate（次水楊酸鉍）**：有水楊酸鹽暴露的顧慮，優先選擇其他藥物。
- 發燒、血便、劇烈腹痛或腹脹時，不應自行用 Loperamide 壓制症狀。

**⚠ 就醫警訊**

發燒、血便、劇烈腹痛，或出現口乾、尿量明顯減少等脫水症狀，應就醫。

**底部提醒**

哺乳媽媽拉肚子，先補充水分與電解質；止瀉藥要看情況使用。

---

## 圖卡 6｜哺乳期間胃酸逆流、胃不舒服可以吃什麼？

**先調整生活習慣**

避免吃太飽、飯後立即躺下，減少容易誘發逆流的食物。

**常見可選擇**

- **制酸劑**：如 Calcium carbonate（碳酸鈣）、鎂鋁鹽類，用於短期緩解胃酸不適。
- **Alginate（海藻酸鹽）**：減少胃酸逆流。
- **Famotidine**：抑制胃酸分泌。
- **Omeprazole、Pantoprazole**：必要時由醫師評估使用的 PPI 類藥品。

**注意事項**

- 胃痛原因很多，不一定都是胃酸過多。

**⚠ 就醫警訊**

- 持續劇痛、吐血、黑便或吞嚥困難。
- 產後上腹痛合併頭痛、視力模糊或血壓升高，可能是產後子癲前症，應立即就醫。

**底部提醒**

多種常見胃藥可以在哺乳期間使用，不必因胃藥自行停餵母乳。

## 圖卡 7｜哺乳期間皮膚癢，可以擦藥或吃藥嗎？

**皮膚乾癢**

- 先使用無香料保濕乳液、乳霜。
- 減少熱水洗澡與過度清潔。

**常見可選擇**

- **Hydrocortisone（氫化可體松）外用藥**：適合部分輕度發炎、濕疹，短期局部使用。
- **Cetirizine、Loratadine**：需要口服抗組織胺時，可考慮的選擇。

**擦在乳頭或乳暈時**

- 先確認成分，並由醫師或藥師指導。
- 選擇**低效價**類固醇，使用**乳霜**劑型，避免軟膏。
- **餵奶後**擦薄薄一層；下次餵奶前若仍有殘留，用清水輕輕擦掉。

**⚠ 就醫警訊**

紅腫熱痛、流膿或皮疹擴散，應就醫。

**底部提醒**

媽媽可以擦藥，但要避免寶寶直接接觸或吃到藥膏。

---

## 圖卡 8｜哺乳期間睡不好，可以怎麼做？

**夜奶時**

- 只開小夜燈，不滑手機，餵完比較容易再睡著。
- 寶寶床放在媽媽房間（同房不同床）。
- 換尿布、拍嗝交給家人，媽媽只負責餵奶。

**白天**

- 寶寶睡，媽媽也跟著補眠。
- 早上曬太陽、散步，幫助調整生理時鐘。
- 每天固定時間起床。

**家人分工**

讓家人用擠出的母乳餵一餐，換媽媽一段完整睡眠。

**咖啡因**

每天 1–2 杯咖啡沒問題，下午以後少喝；不要用酒精助眠。

**需要藥物時**

- 部分安眠藥經醫師評估可以短期使用。
- **Melatonin（褪黑激素）**：在台灣屬處方藥，需經醫師評估。
- 不要自行拿感冒藥或抗過敏藥當安眠藥。

**重要提醒**

使用鎮靜或助眠藥物後，不要和寶寶同床睡，並留意寶寶是否異常嗜睡、喝奶變差。

**⚠ 就醫警訊**

持續失眠，合併情緒低落、容易哭泣、焦慮或無法放鬆，請就醫評估是否為產後憂鬱或焦慮。

**底部提醒**

睡不好不只能忍耐，先從這些方法開始。

## 圖卡 9｜哺乳期間乳房脹痛、塞奶怎麼辦？

**先減少腫脹與發炎**

- 依寶寶需求正常哺乳，不需刻意增加餵奶或擠奶次數。
- 可以使用**冷敷**減少疼痛與腫脹，不建議長時間熱敷。
- 避免用力按摩、推揉或過度擠奶。

**常見可選擇**

- **Ibuprofen（布洛芬）**：緩解疼痛與發炎。
- **Acetaminophen（乙醯胺酚）**：緩解疼痛或發燒。

**⚠ 何時就醫？**

- 乳房明顯紅腫熱痛、發燒、畏寒或全身不適。
- 症狀惡化，或經適當照護 12–24 小時仍未改善。
- 若懷疑乳腺炎，應評估是否需要抗生素。

**底部提醒**

塞奶不要用力揉，也不要為了「排空」而一直擠奶。

## 附：孕期版與哺乳版的主要差異（網頁文字用）

| 症狀 | 孕期與哺乳期的主要差異 |
| --- | --- |
| 頭痛、發燒 | 哺乳期可考慮 Ibuprofen，不必套用孕期的限制 |
| 鼻塞、過敏 | 需考慮 Pseudoephedrine、Methylephedrine 降低奶量的問題 |
| 咳嗽 | Dextromethorphan 可考慮；Codeine、Dihydrocodeine 不建議使用 |
| 便祕 | 氧化鎂、Lactulose、PEG、部分刺激性瀉劑均有哺乳期使用依據 |
| 腹瀉 | Loperamide 可在合適情況下短期使用 |
| 胃酸逆流 | 制酸劑、海藻酸鹽、Famotidine、部分 PPI 都有可用選擇 |
| 皮膚癢 | 特別注意乳房、乳頭塗藥後寶寶直接接觸的風險 |
| 失眠 | 部分處方助眠藥可經評估短期使用；需留意產後憂鬱與照顧嬰兒的安全 |
| 乳房脹痛 | 冷敷、正常哺乳、避免過度擠奶和深層按摩是重點 |
