# 藥局衛教助手 Brand Guide v2.3

更新：2026-10-22

## 1. 正式母版的優先順序
1. **唯一已核准的彩色 Logo 外觀母版：** `assets/logo_primary_color_original.png`（2048 × 684）。其臉型、鬍鬚、眉眼與手寫「助手」不可改變。
2. **已核准的單色外觀參考：** `assets/logo_monochrome_black_light_background.png` 與 `assets/logo_monochrome_white_dark_background.png`（兩者皆含背景）。
3. **透明背景衍生檔：** `assets/logo_primary_transparent.png`、`assets/logo_black_transparent.png`、`assets/logo_white_transparent.png`，為以原圖製作的便利用圖，**需視覺驗收後方列正式發布資產**。
4. **SVG：暫停精修。** 既有 `logo_vector_refined_draft_v2.2.svg` 和 `logo_vector_autotrace_reference_only.svg` 僅是技術草稿，**不是正式 Logo 母版**。

## 2. 品牌定位與外觀
品牌應呈現專業且親切的藥局衛教感受；定稿 Logo 為紅色笑臉、濃黑眉毛和相連八字鬍與落腮鬍、細眼睛及微笑，右側是保留原筆跡的藍色手寫「助手」。既有向右約 8° 的視覺傾斜不得再疊加旋轉。

## 3. 正式品牌色（已核准）
| 名稱 | HEX | RGB | 用途 |
|---|---|---|---|
| 品牌紅 | `#FD2828` | 253,40,40 | 臉部 |
| 品牌黑 | `#101010` | 16,16,16 | 眉鬍及黑色單色版 |
| 品牌藍 | `#013E9C` | 1,62,156 | 手寫「助手」 |
| 品牌白 | `#FFFFFF` | 255,255,255 | 白底／白色單色版 |

這些顏色是已核准標準值。原始 PNG 因抗鋸齒和畫面處理可能有近似像素；不得因此改變原始母版。

## 4. 統一使用規則
- 製作網站、社群貼文、衛教圖卡時優先**直接引用既有圖片資產**，不可讓影像生成模型重畫 Logo。
- 維持原圖比例，**不可獨立改變臉與文字的相對位置**、拉伸、重畫文字、套用旋轉或改形。
- 使用單色版時先評估背景與對比；透明版若有白邊、暗邊或缺筆畫，回退使用原始檔或重作去背，不可透過重畫補救。
- 一般網站可視需求輸出小尺寸 WebP / PNG，但不得回頭覆寫原始母版。
- 既有的幾何量測為近似值；在沒有必要前不再投入逐區曲線精修。

## 5. 浮水印與圖卡署名：**未定稿**
過往曾試驗單色、右下方空白位置、小尺寸與白色柔和漸層，但**大小、固定位置、不透明度、是否強制套用及漸層參數均未核准**。70%～90% 指的是曾測試的**白色背景漸層**不透明度，不是 Logo 本身的不透明度。不得自動批量套用、更動衛教文字或覆蓋警語。

## 6. 資產品質與後續工作
- 原始檔是品牌外觀的最高權威；透明衍生 PNG 為程序去背，不代表人工完成每一像素校對。
- `透明Logo_三色三背景對照.png` 是跨背景的目視驗收圖。
- 不在此版宣稱存在已核准的向量母版。將來若有大型印刷等需求，再一次性交由向量設計師處理。
