# 藥局衛教助手 Brand Guide v2.1

**文件狀態：** 已整合正式品牌色；圖卡浮水印規則仍未定稿。  
**更新日期：** 2026-10-22

## 1. 品牌定位
「藥局衛教助手」：專業又親切、清楚易懂的衛教圖卡品牌。品牌強調可靠的藥學衛教、手機友善的閱讀體驗與一致的視覺來源識別。Logo 不代表醫療內容已完成臨床審核。

## 2. Logo 組成與已確認事項
- 主要完整組合：紅色笑臉與黑色鬍鬚頭像（左）＋藍色親筆手寫「助手」（右）；整體使用白色背景。以 `assets/logo_primary_color_original.png` 作為已選定彩色組合的**圖像來源**。
- 臉部識別：紅臉、濃眉、細眼睛、微笑；上揚八字鬍與圓潤落腮鬍連成一體。設計意圖為頭像向右順時針約 8°，不可再另轉一次 8°。
- 手寫字必須維持原定稿筆跡，不用字型重打，也不能由影像模型重寫。
- 已核可的色彩使用型態：彩色完整版、白底黑色單色、深色底白色單色。單色版的現有檔案是已確認的視覺範例，**內含背景**，不可假設是透明 Logo 素材。
- 官網藥師版保留深藍灰、民眾版保留淺藍白色，品牌紅僅小範圍點綴；此為方向，不等同完成所有 CSS 色碼定稿。

## 3. 正式品牌色（Approved）
以下色碼已於 2026-10-22 核准，取代 v2.0 中的暫定色碼。

| 色彩名稱 | HEX | RGB | 使用位置 |
|---|---|---|---|
| 品牌紅 | `#FD2828` | 253, 40, 40 | 臉部主色 |
| 品牌黑 | `#101010` | 16, 16, 16 | 鬍子、五官線條、淺色背景單色版 |
| 品牌藍 | `#013E9C` | 1, 62, 156 | 手寫「助手」 |
| 品牌白 | `#FFFFFF` | 255, 255, 255 | 白色背景、深色背景單色版 |

### 色彩使用規則
1. 彩色 Logo 一律使用上述三個正式品牌色（加背景白）。
2. 不得任意調整色相、明度、飽和度，或以相近色替代。
3. 單色版本仍可使用，但僅限於已確認的單色資產或後續驗證過的透明版。
4. 網站與圖卡中的其他 UI 配色，可另行設計；不得據此推論整站都要改用品牌紅或品牌藍。

## 4. 比例與幾何（v1 近似量測，待向量精修）
以頭像可見高度 H = 1。
- 臉寬：約 `0.994H`
- 字寬：約 `0.913H`
- 字高：約 `0.540H`
- 臉字空隙：約 `0.106H`
- 字標底部相對臉底部：約 `-0.050H`（字標底較高）

參見 `data/geometry.json` 與 `assets/logo_geometry_annotation_v1.png`。

### 留白建議
以完整橫式 Logo 的可見最外邊界向四周至少留 `0.25H`，作為**提案基準，尚未確認為強制標準**。

### 幾何限制
- 禁止裁切、水平或垂直拉伸。
- 禁止重新描繪眉眼鬍鬚。
- 禁止改寫手寫字。
- 禁止任意更動臉字距離或加陰影。

## 6. 單色版本
- 淺色背景：使用 `assets/logo_monochrome_black_light_background.png`
- 深色背景：使用 `assets/logo_monochrome_white_dark_background.png`

這兩份單色圖檔目前可作展示與使用方向確認；若要製成透明覆蓋圖，必須先從原檔安全分離圖案與背景、保留每一條線，並與核可版本逐像素／視覺比對；不可重畫。

## 7. 浮水印／圖卡署名：**尚未定稿**
目前只確認「可以測試」，尚未確認固定大小、固定位置、透明度或是否批次套用。先前討論的右下角、白色柔和漸層、避開文字等都屬**試驗方向**，不是正式規範。

在規範定稿以前：AI 或 Codex **不得自動批次把 Logo 壓到所有圖卡上**；僅能在明確指定單張、使用指定原圖的前提下製作對照測試，保留原始檔，要求人工審核。

## 8. 建議應用與限制
- 網站頁首／品牌頁使用原始彩色 Logo；已確認網站整合外觀可接受。
- 一般圖卡不預設修改原有衛教插畫、文字或警語；品牌標誌不能覆蓋任何醫療重點。
- 圖卡小尺寸應優先確保文字清楚和單色形狀辨識度，必要時可暫不放署名，不能靠裁切或變形擠進空白。
