# 素材規範（母本）

圖卡素材＝**定稿文字**＋**不含 Logo 的圖卡圖片**。素材在網站外完成，交給網站作業時必須已定稿；網站作業不再查核或修改內容。

本檔是素材規則的唯一正式版本。製圖工具讀不到本檔，所以各工具裡另貼一份節錄（見最後一節）；改規則時先改本檔，再重新貼到各工具。

---

## A. 文字定稿（交給負責文字與醫療查核的 AI）

1. **兩份文字分開寫**：
   - **圖卡文字**：要畫在圖上的字，精簡、一張卡一份。
   - **網頁文字**：每張卡的標題、摘要、分段重點（小標＋內文），給網站顯示與搜尋用。
   圖卡文字不塞入網頁文字、關鍵字或 FAQ。
2. **醫療內容**：藥名、成分、濃度、劑量、單位、年齡、頻次、步驟、警語要完整、正確；兩份文字之間不可矛盾。
3. **來源**：優先使用食藥署核准仿單、官方衛教、專業學會指引；每張卡列出直接來源（名稱＋網址）。產品例子只在有可查證的仿單或確認過的品名時才放，否則不放。
4. **日期與歸屬**：內容更新日期、資料查核日期，以及修訂歸屬，都要是真實的，不可捏造。
5. **複核狀態**：AI 查核不等於藥師複核；藥師未具名複核前，一律視為「待複核」。
6. **選填**：藥品頁的食藥署仿單（品名＋許可證字號）、推薦閱讀（標題＋網址）、系列要不要連到計算器等工具。

## B. 製圖（交給生成圖片的 AI）

**在 repo 內用 AI 製圖時**（任何 AI 都適用）：
- 產出每張一個**不含 Logo** 的 PNG，檔名例如 `<系列ID>_01.png`，連同下方 7 項成品檢查結果一起交付。
- 不修改網站：不改 `cards.json`、`cards.manual.json`、`data/card_content.json`，不執行 `build.py`，不 commit、push。要上網站時改依作業卡辦理。
- 圖卡文字與網頁文字矛盾、數值看起來有誤時，指出差異並停下來問，不自行修改醫療內容；也不標記任何複核狀態。

### 比例與滿版
- 直式 **9:16**，建議 1080×1920。
- 背景延伸到四邊滿版，**不可有白邊、外框或補白**。產出的比例不對就重產，不用補白湊成 9:16。

### 版面
- **標題**：靠左，占上方約 7%～10% 高度；標題沒用到的上方空間可以放插圖。
- **中間內容**：依主題自由排版，例如漫畫、比較圖、步驟、Q&A、人物或產品示意，不套固定模板。
- **整體**：專業、親切、手機直立閱讀清楚；同一系列各張的標題字級與邊距一致。

### 文字
- 圖卡文字**逐字照用**，不增刪、不改寫，數值與單位完全一致。
- 使用台灣繁體中文與台灣慣用語。
- 內容放不下時，先調整版面；仍放不下就建議拆成兩張，**不偷刪字、不縮成密集小字**。
- 指定使用仿單表格時，欄位、數值、對應關係完整保留，可以美化，但不能改成別的劑量表。

### 圖像
- 依產品照片畫示意圖時可以卡通化，但要保留辨識特徵，不虛構包裝上的文字。
- 人物、藥品、劑量示意不可造成誤解。
- 不生成假的 QR code 或條碼。

### Logo 區（右下角）
- 右下角**寬 20%、高 6%** 的範圍之後會疊上正式 Logo。
- 背景照常延伸到角落，**不要畫白框、色塊或留白區**。
- 這個範圍內不放任何文字、警語、來源或重要圖案。
- **不要畫任何 Logo、品牌標誌或「藥局衛教助手」字樣。**

### 成品檢查（交件前逐項確認）
1. 9:16、四邊滿版、沒有白邊。
2. 文字與圖卡文字完全一致：藥名、數值、單位、警語都對，沒有錯字。
3. 表格的列與欄對應正確。
4. 沒有截字、文字重疊、過小的字或漏掉的警語。
5. 以 360 px 寬預覽（手機寬度）時，文字仍然看得清楚。
6. 右下角 Logo 區沒有文字或重要圖案，也沒有畫出任何 Logo。
7. 圖的內容與網頁文字一致。

有任何一項不符就修正或重產；修不好的項目要明確列出，不宣稱全部通過。

### 工具與費用
- 只用現有帳號可用的功能，不設定需另外付費的 API、不索取 API key。
- 環境無法生圖時，說明限制，並提供可以貼到圖像生成工具的完整提示詞，不把提示詞當作完成的圖卡。

## C. 交件給網站作業

交件內容就是網站作業卡 1 第 0 步要求的素材：
- 每張一個 PNG（符合 B 的規定、不含 Logo），檔名能對應到張數，例如 `<系列ID>_01.png`
- 逐頁網頁文字、來源、兩個日期、修訂歸屬（符合 A 的規定）
- 系列資訊：系列 ID、標題、民眾或藥師、分類、icon、搜尋標籤
- 選填項目（A-6）
- 一行交接紀錄：圖片檔名、對應文字的版本或日期、藥師已確認定稿（日期）。網站作業會把它寫進 evidence 檔。
